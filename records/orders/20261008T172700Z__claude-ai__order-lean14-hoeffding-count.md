## The work, in this order

1. **How many trades are enough: a Hoeffding count.** In EdgeGrowth (same module; add `import Mathlib.Probability.Moments.SubGaussian`), under LEAN-13's setting for (b) (returns `X n` measurable, `iIndepFun X μ`, `∀ n, IdentDistrib (X n) (X 0) μ μ`, `-c ≤ X n ≤ C`, `0 < c`, a constant stake `0 ≤ l < 1/c`), prove, for every `N : ℕ` and `L : ℝ` with `L ≤ N * growth μ (X 0) l`:

   ```
   μ.real {ω | wealth (fun _ _ ↦ l) X N ω < Real.exp L} ≤
     Real.exp (-2 * (N * growth μ (X 0) l - L) ^ 2 /
       (N * (Real.log (1 + l * C) - Real.log (1 - l * c)) ^ 2))
   ```

   In words: after N trades, the chance the wealth is still below the target `exp L` is at most that exponential; it shrinks once `N * growth` passes `L`. Since reaching the target by time N is implied by being at or above it at time N, the same number bounds the chance of not yet having reached it.
   - Route: `Z i = Real.log (1 + l * X (i + 1))` lies in `[log (1 - l c), log (1 + l C)]` (LEAN-13's `one_sub_mul_le_one_add_mul`, `Real.log_le_log`); its mean is the growth (`IdentDistrib.integral_eq`, as in `tendsto_log_wealth_div`). Apply `ProbabilityTheory.hasSubgaussianMGF_of_mem_Icc` to each `-Z i` (or to `Z i` and negate; the parameter is `((‖b - a‖₊ / 2) ^ 2)`), then `ProbabilityTheory.HasSubgaussianMGF.measure_sum_range_ge_le_of_iIndepFun` with `ε = N * growth - L ≥ 0`; independence of the `Z i` from `hind` by composing with the measurable map and precomposing with `(· + 1)` (`iIndepFun.comp`; `ProbabilityTheory.iIndepFun.precomp` with an injective map, as Mathlib's Probability/Moments/SubGaussian.lean does inside `sum_of_iIndepFun`). `wealth < exp L` iff the sum of the `Z i` is below `L` (`Real.log_prod`, `Real.exp_lt_exp`, `Real.exp_log`, positivity from `wealth_const_pos`), which implies `ε ≤ ∑ (growth - Z i)`; finish with `measureReal_mono`. Lean's `x / 0 = 0` makes the right side `1` when `N = 0` or the range is `0`, so those cases need no extra hypothesis; a probability space is nonempty, which gives `-c ≤ C`.
